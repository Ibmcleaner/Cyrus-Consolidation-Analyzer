# Upload instructions

1. Extract the ZIP on your computer.
2. Open its extracted folder. Find `README.md`, `app.py`, `cyrus_intake/`, `tests/`, `docs/`, and `examples/`.
3. In the existing GitHub repository, choose **Add file → Upload files**.
4. Drag the contents—not the ZIP or an extra enclosing folder—into the upload area. Keep subfolders intact.
5. Confirm `README.md` is at the repository root, replacing the earlier README. The detailed case study is now under `docs/`.
6. Commit with: `Add reviewed source, offline demo, tests, and engineering documentation`.
7. Check the README links and file tree after committing.

Include `.gitignore` and `.dockerignore`; enable hidden-file visibility if necessary. No deployment action is part of this upload. Do not upload the original review archive, private PDFs, cloud backups, or credentials. No license was chosen on your behalf.
